# Before 기준선 결과 (학습 전 Qwen2.5-VL-3B, zero-shot)

평가 대상: LEMONADE test split의 Perception/Reasoning **2,852문제**
(test 참가자 = YH2003·YH2029·YH2030, 학습에서 한 번도 안 본 사람들)
채점: 논문 방식(프레임 8장 + 논문 프롬프트, greedy, A/B/C/D 추출). 찍기 = 25%.

## 1) 정확도 (이미지 포함)
| 구분 | 정확도 |
|---|---|
| **전체** | **41.0%** |
| Perception | 40.7% |
| Reasoning | 41.4% |
| easy / medium / hard | 46.0% / 41.3% / 34.0% |

→ 찍기(25%)보다 확실히 높지만 59%는 틀림 = **파인튜닝으로 올릴 여지가 큼.**
→ 어려울수록 급락(hard 34%)은 세밀한 행동 구분이 약하다는 신호.

## 2) V(비전) 기여도 — 이미지 vs 텍스트만
| 구분 | 이미지 있음 | 텍스트만 | 차이(V 기여) |
|---|---|---|---|
| 전체 | 41.0% | 28.2% | **+12.9** |
| Perception | 40.7% | 28.8% | +11.9 |
| Reasoning | 41.4% | 27.5% | +13.9 |

**해석 (핵심):**
- 텍스트만 = **28.2%**, 찍기(25%)에 거의 근접 → 질문이 언어 편향(보기만 보고 찍기)으로는
  거의 안 풀린다. 즉 **정답에 이미지가 반드시 필요**하다.
- 이미지가 정확도를 **+12.9%p** 끌어올림 → "V가 실제로 일하고 있다"는 직접 증거.
  ("VLM인데 사실상 텍스트 테스트 아니냐"는 의문에 대한 정량적 답.)

## 3) 이 실험에서의 의미
- before가 41%라 학습 실험이 유의미(개선 공간 넉넉).
- after(파인튜닝) 평가 시 이 표와 같은 항목으로 비교 → 향상폭이 결론.
- 재현: `out/eval_before.json`, `out/eval_textonly.json`
