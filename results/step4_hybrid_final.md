# STEP 4 — 하이브리드 재학습 최종 (base vs v2 vs v3 vs v3b)

영상 단위 split. **홀드아웃**(평가) = NIST cornoil + DVIDS + northants (fire 71·smoke 7·정상 59).
**학습**(별도 영상) = 소방서/데모 실화재 + ASMR 정상 조리영상 + (버전별) 합성.

| 지표 | base(프롬프트만) | v2 합성 460 | v3 실+합성발연 379 | **v3b 실데이터만 290** |
|---|---|---|---|---|
| fire 재현율 | 71/71 | 71/71 | 68/71 | 68/71 |
| 발연 위험 감지 | 7/7 | 7/7 | 4/7 | 4/7 |
| 발연 3분류 | 42.9% | 28.6% | 0% | 0%(미학습) |
| LEMONADE 정상 오탐(오버헤드) | 2.5%/0% | 0%/0% | 22.5%/24% | **0%/0%** |
| **스토브 정상 오탐(홀드아웃)** | **76.3%** | 94.9% | 55.9% | **47.5%** |

- v2 = 합성 불꽃(조리배경) + D-Fire. v3 = 실 스토브 정상 + 실 화재 + **합성 발연**. v3b = 실 스토브 정상 + 실 화재(합성 제외).

## 결론 (명확)
- **실 in-domain 데이터가 오탐을 실제로 줄인다.** 스토브 감시 프레이밍 오탐 **76% → 47.5%**(거의 반감),
  게다가 LEMONADE 정상은 0%로 유지. **파인튜닝이 처음으로 핵심 지표에서 base를 이김.**
- **합성은 해로웠다**: v2(합성 불꽃)는 오탐 95%로 악화, v3의 합성 발연은 "LEMONADE=위험" 오학습 유발(22%↑).
  → 합성을 뺀 v3b가 가장 깨끗.
- **비용**: fire 재현율 100%→96%(3장 놓침), 발연(smoke) 클래스는 실 학습데이터 없어 미해결.

## 한 줄 요약
소량의 **실 조리화재 영상(영상 단위 split, 실 정상 + 실 화재)** 만으로 스토브 정상 오탐을 76%→47.5%로 낮췄다.
합성 데이터는 오히려 편향을 키워 해로웠다. **정공법 = 실데이터 규모 확대.**

## 남은 과제
1. **오탐 47.5%는 아직 높다** — 실 정상/화재 영상을 더 늘리면(현재 영상 ~7개) 추가 개선 여지 큼.
2. **발연(smoke) 클래스 미해결** — 실 발연 데이터 필요(사용자 기름 발연 촬영이 최선).
3. fire 재현율 소폭 회복(놓친 3장 분석) + 과적합 점검(train_loss 0.05로 낮음, 데이터 확대로 완화).
