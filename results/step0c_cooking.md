# STEP 0-C — 조리 도메인 홀드아웃 재측정 (기본 Qwen2.5-VL-3B)

원래 STEP 0은 **야외** D-Fire로 쟀다. 이 프로젝트 도메인은 **주방**이므로, 조리 도메인 실데이터로 다시 쟀다.

## 데이터
- 위험(불꽃): NIST cornoil 팬 화재 크롭 10장 / 발연(smoke) 4장
- 정상: cornoil 빈 팬 18장(같은 리그) · LEMONADE 랜덤 조리 40장 · LEMONADE hard(김/튀김) 25장
- 누수 방지: 위험·정상을 서로 다른 소스로 한 F1에 섞지 않고 **3개로 분리 측정**(배경으로 못 가르게).

## 결과
| 측정 | 값 | 뜻 |
|---|---|---|
| 실화재 재현율(Recall) | **10/10 = 100%** | 진짜 조리 불꽃은 다 잡음 (D-Fire 0.97과 일치) |
| **랜덤 조리 정상 오탐률** | **15%** | 평범한 집 조리도 7장 중 1장 "fire"로 오경보 |
| **hard 조리 정상 오탐률(김/튀김)** | **44%** | 김·튀김·주황음식 정상 장면의 절반 가까이 오경보 |
| **발연(smoke) → 'fire'로 답** | **100% (4/4)** | 발연을 불과 구분 못함(단계 감각 없음) |
| 참고: 원래 D-Fire(야외) | F1 0.819, 오탐 40% | — |

(cornoil 내부 불꽃 vs 빈 팬: F1 0.526 — 단, 빈 팬 프레임도 전부 fire로 답함.
 이 리그의 빈 팬 프레임이 어둡고 애매해 음성으로 덜 깨끗 → 핵심 신호는 위 재현율/오탐률.)

## 해석 (방향 결정)
- **문제가 도메인 안에서 실재하고, 심각하다.** 기본 모델은 불은 잘 잡지만(재현율 100%),
  **정상 조리를 화재로 착각하는 오탐이 심하다** — 흔한 김·튀김 장면에서 44%.
  실시간 로봇 시스템(1~3초 주기)이면 사실상 상시 오작동(헛정지)이다.
- **발연을 불과 구분 못함(100% fire)** → "정상 김 → 위험 발연 → 화재"의 단계 판단 능력 없음.
- 야외 D-Fire(오탐 40%)와 비교해도 **조리 도메인 오탐이 같거나 더 심하고, 게다가 정상 운영 중 늘 나오는 장면**에서 발생한다.

→ **파인튜닝 태스크의 정당성이 수치로 확보됨:** "김·튀김·주황음식·달군 팬 = 정상(경보 X),
   진짜 불꽃·위험 발연 = 위험(개입)"을 가르치는 것. 가능하면 normal/smoke/fire 3단계로.

## 한계 (정직하게)
- 위험 양성이 아직 10(+4)장, 단일 리그 → 부피·다양성 부족. 오버레이 없는 소스(사용자 발연·chip-pan)로 보강 필요.
- hard 오탐 44%는 김/튀김을 일부러 고른 스트레스 슬라이스, 랜덤 15%가 대표 수치. 둘 다 보고.
