# STEP 4 — 파인튜닝 결과 (base vs 합성-only vs 개선+하이브리드)

Qwen2.5-VL-3B base에서 QLoRA SFT. 평가는 실 홀드아웃(NIST cornoil 화재/발연 + LEMONADE 정상).

| 지표 | base (프롬프트만) | v1: 합성 360 | v2: 개선+하이브리드 460 |
|---|---|---|---|
| fire 재현율 | 10/10 | 10/10 | 10/10 |
| 발연 위험 감지 | 4/4 | 4/4 | 4/4 |
| 발연 3분류('smoke' 정확) | 50% | 50% | 50% |
| **조리 정상 오탐 (랜덤 40)** | 2.5% | 7.5% ↑ | **0%** ✓ |
| **조리 정상 오탐 (hard 25)** | 0% | 8.0% ↑ | **0%** ✓ |
| cornoil 빈팬 오탐 (18) | 61% | 72% | 100% ↑ |

v2 = 불빛 glow + 리밸런스(정상↑) + 불꽃 다양화(NIST+D-Fire) + 하이브리드(D-Fire 원본 실화재 40) + 홀드아웃 세그먼트 제외.

## 해석 (정직하게)
- **v2가 v1의 오탐 악화를 되돌렸다.** 실제 홈 조리 정상에서 오탐 0%/0% → 개선안(glow·리밸런스)이
  "조리배경=위험" 편향을 잡았다. **엔지니어링 교훈: v1 오탐은 합성 리얼리티·밸런스 문제였다.**
- **그러나 base 대비 "명확한 승리"는 아니다.** base도 좋은 프롬프트로 이미 2.5%/0%였고, v2는 0%/0% —
  표본이 작아(1/40→0/40, 0/25) 사실상 **동급**. 정말 어려운 부분(발연 3분류 50%)은 **그대로**.
- **cornoil 빈팬 오탐 100%** — v2가 어둡고 열원이 달군 랩 리그 빈팬을 전부 "위험"으로. 이 프레임이
  애매(달군 코일=위험 조짐)해 라벨 자체가 모호. 대표 조리 장면은 아니나, "달군 열원=위험" 쪽 과반응 신호.

## 두 번의 실험이 말하는 것
- 파인튜닝은 **잘 만든 프롬프트를 쓴 base를 아직 뚜렷이 못 이긴다.** v2는 v1의 실수를 고쳐 동급으로 왔을 뿐.
- 개선 여지가 있는 곳(발연↔화재 단계 구분)은 두 번 다 안 움직였다 → 여기가 진짜 어려운 태스크.
- **홀드아웃이 너무 작다**(fire 10·smoke 4·정상 65) → 결론의 신뢰구간이 넓다. 부피·다양성이 급선무.

## 다음 (우선순위)
1. **홀드아웃 부피·다양성** — 오버레이 없는 실조리 화재/발연(사용자 촬영·chip-pan·DVIDS)로 fire/smoke를
   각 50~100장까지. 지금 결론은 표본이 작아 약하다. **이게 1순위.**
2. **발연↔화재 단계 데이터** — 50%에 멈춘 지점. 실 발연 영상(사용자)로 smoke 클래스 실물 보강.
3. **in-domain 실화재 하이브리드** — 이번 하이브리드는 야외 D-Fire라 도메인 어긋남. 조리 도메인 실화재가
   학습에 필요(=홀드아웃과 분리한 별도 조리 실화재 확보가 관건, 여전히 데이터 병목).

## 전략적 결론
"합성 파인튜닝으로 소형 VLM이 조리 위험을 더 잘 본다"는 논지는 **2회 실험 후에도 미입증**이다.
잘 만든 프롬프트가 오탐을 대부분 해결하고, 파인튜닝은 아직 그걸 못 넘는다.
→ 가치를 증명하려면 **(a) 프롬프트로 안 되는 발연/화재 단계 구분**을 실 데이터로 공략하거나,
  **(b) 논지를 "온디바이스 실시간·distillation"으로 이동**해야 한다. 데이터(특히 홀드아웃) 확보가 모든 것의 선결.
