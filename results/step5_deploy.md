# STEP 5 — 배포 지표 (홀드아웃 재정의)

기존 "스토브 정상 오탐 52~76%"는 홀드아웃 정상이 **적대적 프레임**(발화 직전 팬 + 어두운 랩 리그)에
편중돼 실제보다 나쁘게 보였다. 정상 조리영상 3개를 **홀드아웃 전용 "일상 스토브 정상"**(120장, 학습 미사용)으로
예약하고, 나머지로 재학습(v6) 후 범주별로 측정.

## 배포 스코어카드 (base vs v6)

| 범주 | base | v6 | 의미 |
|---|---|---|---|
| **일상 스토브 정상 (핵심)** | 8% | **2%** | 실제 배포에서 흔한 조리 → **오탐 지표** |
| 일상 LEMONADE(오버헤드) | 2% | 0% | 다른 앵글 일상 조리 |
| 발화 직전(경계) | 83% | 49% | 화재 몇 초 전 팬 → "곧 위험" 회색지대 |
| 랩리그(cornoil) | 61% | 33% | 어두운 실험장치 → 비대표적 |
| **fire 재현율** | 71/71 | 66/71 | 화재 감지 |
| smoke 재현율 | 7/7 | 4/7 | 발연 감지 |

## 결론 (핵심 반전)
- **실제 배포 지표(일상 스토브 정상 오탐)는 v6에서 2%** — base 8%에서 개선. 배포 가능한 수준.
- 앞서 본 "52~76%"는 **적대적 프레임 탓**이었다. 범주를 나누니 파인튜닝이 **모든 범주에서 오탐을 낮춤**
  (일상 8→2, 경계 83→49, 랩 61→33).
- **트레이드오프(정직하게)**: v6는 오탐을 줄인 대신 **fire 재현율 100%→93%**(5장 놓침), smoke 7→4.
  화재 안전 시스템에선 미탐이 오탐보다 위험 → 실배포는 이 동작점을 데이터·임계값으로 재조정해야 함.
- **경계(발화 직전) 49%**는 사실 "곧 위험" 신호라, 별도 조기경보 클래스로 다루면 오탐이 아니라 기능이 됨.

## 종합 (프로젝트 방향 판정)
- 합성 → 해로움 / 실화재 과다 → 해로움 / **실 정상 대량 + 홀드아웃 재정의 → 배포 지표 확보(일상 오탐 2%)**.
- **방향은 현실성 있다**: 실 조리 데이터로 일상 오탐을 배포 가능 수준(2%)까지 낮췄고,
  남은 난제(발화직전 회색지대, 발연, fire 재현율 회복)는 데이터·클래스 설계 문제로 좁혀졌다.
